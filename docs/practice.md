# 纸间 Practice 使用说明

[打开在线版](https://burntroses.github.io/paper-notebook-practice/) · [下载离线版](https://github.com/BurntRoses/paper-notebook-practice/releases/latest)

## 查看完整试卷

进入「完整试卷」，搜索卷名、科目或考试。可按方向、地区和语言筛选，并区分真题与原创模拟。同一条目包含题目卷及可用答案；套卷另配答题卡时才显示答题卡。发布单位、原件链接和许可可展开查看。

## 制作与编辑

1. 复制首页的 Agent 或对话提示词，和教材、题库或其他资料一起发送；没有资料就说明科目、适用对象和考试范围。按提问补充需要确认的要求，取得可导入的 `practice.json` 文件。首页的组卷示例只用于预览。
2. 在「导入试卷」打开生成的纸间 JSON。在「我的试卷 → 版式」调整纸型、方向、栏数、字体、题距和页边距，点击「应用设置」。
3. 点击「导出试卷」。要继续编辑正文、编号、表格和公式，选 Word；要按预览版式打印，选 PDF；要下次接着改，选「可编辑文件」。也可导出 PNG、离线 HTML 或整套试卷包。

「我的试卷 → 打开文件」可导入已有题库或整理 Word、纯文本和 Markdown 资料。PDF 与扫描件先用本机 Skill 提取并核对。导入文件保存在当前浏览器中。

## 离线使用

解压完整离线包，打开「纸间-试卷预览.html」。需要读取扫描件或用命令行出卷时，按 [Skill 说明](https://github.com/BurntRoses/paper-notebook-practice/tree/main/skills/paper-notebook-practice)安装对应工具。
