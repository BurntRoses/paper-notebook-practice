# 考公：行测与申论

先读 [研究流程](research-workflow.md)。路线为 `civil-aptitude` 与 `civil-essay`。明确国考/省考、年度、地区及职位类别；“考公”本身不足以核定一个完整规格。国考类别和各省A/B/C不能机械对号；同省不同年也重新核定。

## 行测：让每个模块测到真实能力

按目标年度大纲决定模块，不把某年培训分类当成永恒模板。政治理论、常识等时效内容需要发布机构与适用日期。言语题的正确答案与每个干扰项都对应具体语义或逻辑；长短、语法与措辞不得暗示答案。

数量关系先列变量、约束与方程，再计算、估算或构造反例。条件充分性必须分别验证每个条件及联合条件。资料分析将原图表、指标解释和口径作为一组保存；独立复算基期/现期、增量/增长率、倍数/比重、平均数与百分点。题目可考快速估算，但选项间隔必须足以支持允许精度。

判断推理分开处理：定义判断按定义要件，命题推理核对量词与充分必要，分析推理枚举合法状态，论证题区分前提、结论与支持强度。图形推理提供真实、清楚且未变形的图片；画面上有几条线、多少封闭区域等必须实际观察，不能从文本 OCR 猜图。

题库按模块、知识点、能力、原题年度/类别、难度依据及相似变式组织。避免同一个表格重复换数覆盖大量题量；完整题组保留，不把共用材料拆散。

## 申论：从材料到答案，不套范文

申论由注意事项、给定资料和作答要求构成。原题完整保留资料编号、段落、人物身份、出处与时间；不省去看似重复但会影响概括的材料。自拟资料保留多主体、行为、问题、原因、措施与结果的完整逻辑；引用事实必须有来源，虚构练习材料记入作者身份，不能伪装成真实调查。

按题目任务制作不同答案：

| 任务 | 答案组织 | 核对重点 |
| --- | --- | --- |
| 归纳概括 | 对象—核心事实—分类关系 | 每个要点有指定资料依据，层次不重复 |
| 综合分析 | 含义/关系—原因/影响—论证或判断 | 解释回应题问，推断条件充分 |
| 提出对策 | 问题—责任主体—行动—实施条件 | 对策针对材料问题，可执行，不只喊口号 |
| 贯彻执行/应用写作 | 身份、对象、目的、文种与正文内容 | 格式服务任务，不将所有题硬套公文格式 |
| 文章论述 | 论点—分论点—材料与推理—结论 | 紧扣主题，允许合理不同立场和组织方式 |

先输出参考要点，再逐点连到给定资料的页码/段落/连续句，最后分配分值；同义表达按内容评分。作文给内容、论证、结构、语言等可观察档次，并提供示例，不用一篇范文定义唯一正确答案。未取得官方评分细则时，将答案记为独立参考答案，不能把培训“采点表”称为官方规则。

`responseConstraints.maxWords` 与 `countUnit: characters` 保存题面字数要求；给中文长答使用 `answerStyle: grid` 与 `essay-grid` 卡，按题目限制分配字格和续页。短概括题和文章题的作答容量分别核对。

## 已实际读取的版本例子

以下记录于 2026-11-15，供版本判断参考；每次制作仍以用户目标年度为准。

- [2027国考公共科目大纲，上海立信会计金融学院转载](https://jy.slu.edu.cn/2026/1014/c557a58735/page.htm)，2026-10-14发布。正文列行测政治理论、常识、言语、数量、判断、资料分析；行测120分钟/100分，申论180分钟/100分。转载身份须保留，官方入口为国家公务员局招考专题。
- [2027江苏公务员公共科目大纲，江苏人社厅](https://jshrss.jiangsu.gov.cn/art/2026/10/30/art_93733_11852177.html)，2026-10-30发布。A/B/C均含行测与申论；申论能力侧重不同，时长150分钟。此处直接说明不能把国考申论180分钟套到江苏；该大纲仍不足以自动推出全部小题数量和评分细则。

研究报告不必复述完整大纲。保留真正影响蓝图、题面、答案和答题卡的差异即可。
