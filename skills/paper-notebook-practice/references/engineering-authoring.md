# 工程：课程、资格与规范应用

先读 [研究流程](research-workflow.md)。先分清课程考试、考研专业课和执业资格，再分学科、阶段、年度及专业。工程名称相同不意味着相同能力、计分或允许工具。

## 工程课程的真实任务

课程以用户大纲、教材、讲义和教学进度为边界；按 [路线注册表](exam-routes.json) 选理论/材料/结构/流体力学或土木、水利、交通、机械、电气、电子、控制、计算机、化工、热能、材料、环境、安全、测绘、矿业路线。组合学科方法，不把所有工程题写成概念默写。

| 学科组 | 应给的条件 | 应产生的作答证据 |
| --- | --- | --- |
| 力学、土木、结构 | 几何、支承、连接、荷载、材料、边界 | 受力/内力图、方程、变形、稳定或设计校核 |
| 水利、流体、热能 | 控制体、流向、状态、物性、基准、损失 | 守恒、状态/水力计算、效率及适用条件 |
| 机械、交通 | 机构或线路、工况、载荷、材料、约束 | 运动/传动/强度或交通设计计算、方案理由 |
| 电气、电子、控制 | 实际电路/系统图、参考方向、参数、初始/采样条件 | 电路求解、波形、逻辑、稳定与性能分析 |
| 化工、环境 | 流程、组成基准、温压、流量、物性、反应 | 物料/能量衡算、设备/工艺选择与达标解释 |
| 材料 | 成分、温度、组织图/相图、工艺与服役条件 | 相组成计算、机制解释与选材依据 |
| 测绘 | 观测网、坐标/高程基准、投影、精度、单位 | 闭合差、平差、坐标成果与误差分析 |
| 安全、矿业 | 设施/工艺、作业过程、危险源与控制条件 | 风险/通风/稳定计算、事故因果与针对性措施 |

必需图纸不能只留下“见图”；按实际数据画清楚并保留尺寸、节点、箭头和单位。答案包含建模、适用关系、代入、计算、单位与工程解释。用第二算法、守恒、量纲、极限情形或小型程序复核。程序验证与手算证明分别记录。

## 工程资格先确定身份与阶段

- 一/二级建造师：年份、地区（尤其二建）、科目及实务专业；公共科目与案例实务分开。
- 一/二级造价：年份、地区、土建/安装/交通/水利、科目；计量计价、费用、清单与定额版本必须一致。
- 监理：年份、土建/交通/水利、科目，合同与质量/进度/投资的案例保持事件链。
- 注安：初/中级、科目及煤矿、金属非金属矿山、化工、金属冶炼、建筑施工、道路运输、其他等实际专业。
- 注册结构：一级/二级、基础/专业，不能给二级强加不存在的基础阶段。
- 注册岩土、电气、公用设备、化工、环保、水利水电、道路：基础/专业、知识/案例、具体专业方向；基础公共课与专业案例不能共用一套出题蓝图。

## 规范与答案如何可追溯

规范资料记录编号、名称、版本、发布/实施/废止日期、勘误以及目标考试是否指定使用。**考试指定版本不必等于网上最新版本。** 历史原题保留当年解题语境，按现行规则练习时另做改编及依据，不能把新答案写回旧题冒称当年官方答案。

`requiredVersions` 保存用户指定资料版次。`supportingSources.role: standard` 锚定具体条款，`answerProvenance` 区分官方答案、机构解析和独立解答。设计和案例解答写出取值来源、荷载组合、安全系数、公式、代入量与单位；非唯一方案按约束、计算和理由评分。

规范缺页、只搜到摘要或条款冲突时，继续找正文和勘误；无法取得时保留具体未解决项。不要为凑“已完成”捏造条款编号。中文与英文标准的单位、版本与适用区域也须一致。

## 答题卡按任务与年度核定

长计算题需要步骤区、图示区和单位；客观题需要实际选项；专业案例可能同时要求选项与计算步骤。先用用户原卡逐页校准，不按“工程考试”统一套一张纯涂卡。

2026年[湖北勘察设计考试通知](https://rst.hubei.gov.cn/hbrsksw/zyjslks/zyjsry/2026ks/2026kcsjzcgcs/202608/t20260804_5988526.shtml)明确：一级结构专业及岩土、公用设备、电气、化工专业案例在专用卡作答，首页填涂选项，解答步骤写入对应题号框；其余列明专业方式保持原规则。2026年[福建一造通知](https://zjt.fujian.gov.cn/xxgk/gzdt/bmdt/202607/t20260724_7191968.htm)明确土建/安装案例为主客观混合，交通/水利案例为主观。此处是年度差异实例，不代表项目已经内置每种原卡的完整样式。
