# 国际课程、语言、入籍与艺术考试

先读实际附件，再按考试身份选方法。`exam-routes.json` 的国际路线提供学科方法和默认版式；完整考试规格、官方成绩与真实原页另行核定。任务库见[题型与任务模式](question-pattern-library.md)，纸面参数见[模板目录](template-catalog.md)。

## 识别与一次收集

沿用用户消息、资料和定制向导中已经给出的选择。仍有关键缺项时，与其他需求一起问齐：

- 国家/地区、考试局、考试名称、科目代码、场次/年份、试卷或component、考生层级。
- 语言证书的级别、成人/青少年版、纸笔/机考/口试；国际课程的Core/Extended、AS/A Level、AA/AI与SL/HL；入籍考试的适用版本与语言。
- 资料范围、原题/原创偏好、整卷/指定component/题库、允许工具、录音与真实操作条件。
- 原卷复刻或可编辑版；彩印/灰度、色彩是否决定答案、图片分辨率、独立图片册；口试考生卡/考官卡、作品过程册/评分单是否分开。

用户委托按资料或默认值决定时，先用实际官方版本和可靠源件处理，不再为这些已委托项目确认。默认上传优先、原题优先，既有“仅用这些资料”限制继续生效。

## 研究顺序与身份

1. 读取官方大纲、完整公开卷、mark scheme或评分descriptor、勘误及考试形式更新；通过科目代码和有效期确认同一版本。记录URL、读取日期、版次、实际读到的段落/页码。
2. 官方入口未开放完整试题时，继续查公开样题、机构课程资料或用户合法提供的原件。收费、登录、禁止再发布的资料不复制进公共示例包。可依据可读大纲编写原创任务，来源身份仍为`generated`。
3. 按知识/能力、原题号、材料、共享文章/图/录音、作答形式、难度与评分标准组织。一个component可含选择、简答、计算、图像/数据响应、论文、互动口语、实验或作品，不能统一压成概念记忆卡。
4. 先求解、实际听录音、读图或检验可执行产物，再写参考答案和分步量表。官方答案、机构答案、当前Agent独立解答分别记录。作者量表不得冒称官方等级转换。
5. 纸面沿用真实原标题与正式层级；考试形式、收入范围、原创/原题身份和研究记录在元数据与交付说明中说明。新任务不伪造考试局标志或安全标记。

**语言与音频排版。** 日文用支持假名/日文字形的字体，韩文用完整韩文字库；法德文核对变音字符、标点与断词。原文的ruby和注音按题目目标保留，读音题不能因补假名泄题。`presentation.language`支持`zh/en/ja/ko/fr/de`；其他语言先核对字体与渲染再制作。免费字体的实际文件与许可随需交付，不能只在CSS中写一个未安装名称就称已嵌入。实际打开HTML、PDF、Word与PNG检查缺字、标点和行尾。

**听力与口试。** 录音、问题、图像、选项、停顿和播放次数相互对应。考生卷不含脚本与正确答案；考官卡可含追问与量表，答案源保留脚本和证据。无录音时可完成阅读等独立部分；尚未满足的听说component保持明确缺项，不把脚本或题纸当作完整听说成品。

## 入籍与公民知识

先确认国家、手册版本、适用测试和语言；本工具制作学习材料和练习，不要求用户填护照、申请号或身份文件。美国公民知识口试与英国、加拿大、澳大利亚的知识测试分别处理。

- **美国。** 2008与2025版分别保存题号和允许答案。官方2025实施通知以申请时点区分适用版本；2025官方题库为128题，口试最多20问，至少12问正确。2008版的100题/最多10问/至少6对不能混入2025版；特殊适用规则另读当期官方规定。现任官员、州、选区等答案制作及使用前回到官方updates核对，记下日期。纸面问答只是一份口试练习材料，英语读写、实际口头响应及完整面试分别评估。
- **英国。** 内容范围依官方Guide for New Residents。公开官网能核定结构，不等于已读收费手册全文。只从用户合法提供材料或允许来源出题，不把第三方练习库称官方真题。
- **加拿大。** 题源回到Discover Canada。当前官方study页列20道选择/判断题、45分钟、至少15题正确，可英语或法语；不要继续沿用旧30分钟信息。公民知识测试与语言技能证据分开。
- **澳大利亚。** 题源回到Our Common Bond，正式测试用英语。确认整体门槛及values类题的单独条件，答案不能只按总分判定。官方免费样题仅是样本，不代表正式考试出现相同题目。

当用户资料属于历史版本，分别保存历史答案与当前更新，不把现行事实改写进原卷而不留记录。引用规则时以实际适用官方原文为准，不依据社区帖子或搜到的旧摘要。

## 艺术、设计、音乐与彩色科学图题

**作品与过程。** 观察/创作任务至少给出真实对象或图像、媒介、尺寸、时间、目标受众与交付要求。过程草图、材质/色彩实验、方案迭代、最终作品和反思是不同证据。量表用可观察行为分档，参考作品提供一种回应，不把个人审美或模仿示例当唯一正确答案。艺术史题把视觉细节、可核实语境和论点联系起来，允许有证据的不同解读。

**乐理与演奏。** 乐理题包含实际谱例，独立检查谱号、调号、拍号、小节、时值、临时记号和声部；听辨需真正录音。演奏任务按乐器、级别、曲目及现场/录制条件提供任务单、实际音视频与评分记录，依据音高、节奏、音色、乐句和整体表现。任务纸不等于已验证的演奏。ABRSM等机构的乐理、Practical和Performance要求分别核定，曲目列表与现成乐谱的公开可读性不构成再发布许可。

**彩印与灰度。** `presentation.printColor`为`color`或`grayscale`；`job.customization.printColor`为`source`、`color`或`grayscale`。默认保留来源色彩。按所需文件实际检查：

1. 色彩只承担编码时，同步提供文字标签、形状、线型或纹理。附件可用`grayscaleDataUrl`保存经过核对的灰度替代图；修改图后重核答案。
2. 色相/饱和度、染色、遥感通道或作品色彩本身就是测量目标时，将附件设`colorRequired: true`，保留可靠彩色原图。没有经过核对的等价灰度图时，要求彩印或另作独立任务，不能去色后仍声称同题可答。
3. 图像保留完整画幅、图例、色条、比例尺和单位；查看导出后实际像素及打印大小。辨认细节图通常按最终尺寸检验约300 dpi，低分辨率来源不通过放大或锐化伪造细节。
4. 颜色不决定答案的纯文字和细线用清楚的黑白，避免整页背景耗墨。彩色内容与纸白之间保留对比，页面明暗主题不能改变试卷的打印色彩。
5. PDF、Word和PNG逐格式看实际颜色/替代图、字体和分页；Word中图像与PDF中图像分别核对，不把浏览器预览当作全部格式通过。

**图像与声音权利。** 优先用户授权资料、自己创作的图/谱/录音、公版原作及有清楚许可的公开资产。记录作者、作品名、来源URL、许可和修改。原作公版与摄影/录音文件的权利分别核对；图示、谱例和示范音频的原创身份留在元数据。原卷与本项目代码的许可不混用。
