# 考研：按科目代码组合出题方法

先读 [研究流程](research-workflow.md)。明确年度、统考或院校自命题、科目名称/代码、专业与用户指定资料；招生目录证明科目身份，具体题型、范围和分值仍需相应大纲与完整原卷。

## 数一、数二、数三

| 路线 | 组合方法 | 出题边界 |
| --- | --- | --- |
| `postgrad-math-1` / 301 | 高数、线代、概率统计 | 数一目标年度大纲的细目与要求 |
| `postgrad-math-2` / 302 | 高数、线代 | 不纳入概率统计；高数删取仍逐项查大纲 |
| `postgrad-math-3` / 303 | 高数、线代、概率统计 | 按数三而非数一的细目、方法与应用范围 |

不要用数一换标题生成数二，不从“经济”两个字推断数三所有题型。数学以可求解的计算、证明、条件辨析、参数讨论和建模为主体。知识点变成题目时，明确对象、条件、所求量与证明任务，不能让整张卷都变成“写出某概念的定义”。

微积分核对定义域、奇点、可微/连续、端点、定理条件、积分常数与参数分支；线代核对秩、数域、维数、基变换、相似/合同/等价，选择项用反例逐一验证；概率统计先定支持集、分布、独立性与抽样，再核对归一化、参数、自由度、单双侧和置信/检验解释。程序可验算，证明仍给完整理由。

原题优先保留完整条件与小问依赖。缺题时围绕蓝图编写能检验真实方法的题目，独立解后设计干扰项；难度来自步骤、信息组织和迁移，不能靠莫名复杂系数或范围外定理凑难度。答案逐步给分并容纳等价解法。

## 英一、英二

路线为 `postgrad-english-1` / 201 和 `postgrad-english-2` / 204，使用 `english-reading-writing`。分别核定目标年度完形、阅读、新题型、翻译及写作结构。不要套CET听力、57题、125/130分钟或710分报道分。

阅读保留完整文章、题目和备选项，每个正确项有文本依据，干扰项解释具体偏差；新题型核对篇章衔接与全部选项。翻译参考答案按信息单元和表达给分，接受等义译法。写作给实际任务、对象、目的和字数，范文与分档量表同时提供。原题版权与文章出处保留，新编文章不得标为历史原题。

## 政治、199、396、408

- `postgrad-politics` / 101：理论与材料结合，单选/多选逐项判定，分析题给原理—事实—推理链。时政保留日期，历史原题按当时版本核对，不用当前表述无声改写旧题。
- `postgrad-management-199`：数学基础、逻辑与写作组合。数学按199范围，不自动加入大学微积分；问题求解与条件充分性分别处理。逻辑用真值表/反例/枚举核对。论证有效性分析定位实际缺口，论说文评价论点、依据、结构与语言。
- `postgrad-economics-396`：数学基础、逻辑与写作，但数学范围与分值以396当期大纲为准，不直接继承数三。写作两类任务分别设答案与评分。
- `postgrad-computing-408`：数据结构、组成、操作系统与网络。算法题可执行并核对正确性/复杂度；系统题明确字长、编址、大小端、页大小、替换与调度策略；网络核对协议层、bit/byte和发送/传播时延。题面图示、初始状态与时序要足够重算。

## 院校专业课

`postgrad-specialist` 需要“院校—学院—专业—年度—代码—科目名”的联合身份。学校之间相同代码不代表同一科目；同校次年也可能改书、改范围或由自命题换统考。读目标年度招生目录、考试大纲、参考书版次与调整公告；按具体课程再叠加工程、人文、语言或编程策略。

只有回忆题时标记 `provenance.sourceType: recollection`，对缺失条件保留问题；题目来源、答案来源与独立求解分开记录。指定教材范围时，网络题只作为获准的补充，不能悄悄扩展课程。
